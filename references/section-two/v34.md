# V34 — My Saved Looks

Approved PNG: exec-06b3588e-9adc-45c3-8744-288de41a2f1e.png. No image generation for implementation. Existing static portrait assets and native Motion renderer reused.

Source components and measured baseline at 1280×720:
- `#look-name`: AvenirNext 600, 10px/13.2px. Saved names use precisely this font, no underline, centered in a 20px-high target.
- `.fitting-remove`: 20×20px target, #b2b2b2; 16×16px SVG, native trash path/stroke 2.00585, native 8px action gap. Edit uses matching line geometry.
- `.fitting-corners i`: 12×12px legs, 2px #E6E8EA; used unchanged on the full card territory.
- `.fitting-thin-corners`: 1px #b2b2b2, 6px action/name corners, 200ms hover opacity.
- Hero CTA: AvenirNext demibold, native 14px/20px display variant, 50px high, 14px 30px padding, 12px/2px corner marks, 5px hover displacement, backdrop blur 5px. Narrow view button 170px wide per approved narrower PNG; gray RGB153 with .92 alpha to add mild glass without changing hue. Corner marks #b2b2b2.
- Shared third-section navbar remains the actual global component, 40×40px menu button. Small 10px/13.2px AvenirNext regular MY SAVED LOOKS label to its left-side region.

Route `#saved` uses three columns and native vertical scrolling, detached from the four-section wheel controller. Original black fourth section remains unchanged. View opens saved outfit in the fitting room; edit opens its existing details panel. Save updates by savedId instead of duplicating the record. Delete has an Undo action. Storage is browser-local (`fitloop-saved-looks-v1`) and migrates the former saved singleton. Unsaved working models are not represented as saved items.

One shared WebGL renderer draws visible card canvases to avoid a WebGL context per saved look. Motion is static by default; native jitter and subtle sway run only on hover/focus. Reduced-motion settings disable both.

Verification: JS syntax checks, existing navigation regression tests, live native-browser save, menu navigation, direct link and reload, View and Edit actions; compared native source computed styles above.
